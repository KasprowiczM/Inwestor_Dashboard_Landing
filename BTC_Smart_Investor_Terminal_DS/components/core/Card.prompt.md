Glass surface card — the core container. Optional eyebrow + title header and ice/gold glow edge.

```jsx
<Card eyebrow="Okno akumulacji" title="Strefa otwarta" accent="ice" interactive>
  <p>Bottom Score w paśmie DCA od 14 dni.</p>
</Card>
```

`accent`: `ice | gold | null`. Set `interactive` to lift on hover.
